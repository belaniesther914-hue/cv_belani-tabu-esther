# CV Esther - Mon CV en Application Flutter

Bonjour ! 👋 Je m'appelle Esther.
Voici mon CV, mais pas en papier, en vraie application mobile et web, faite avec Flutter.

## ✨ Ce que contient l'application

- Ma photo et ma présentation
- Mes compétences
- Mes expériences
- Ma formation
- Mes contacts

## 🛠️ Fait avec

- Flutter
- Dart
- VS Code

## 🚀 Comment lancer le projet ?

Si tu veux voir mon CV sur ton ordinateur :

1.  Installe Flutter
2.  Ouvre le projet dans VS Code
3.  Dans le terminal, tape :

```bash
flutter pub get
